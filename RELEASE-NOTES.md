# IZ2S SB4 0.25.2 — SmileBASIC 4 Edition

First release of the SB4 line in its own repository, based on IZ2S Platform 0.25.2.

- Dedicated SmileBASIC 4 engine and setup flow.
- Compact sidebar logo and language bar.
- IZ2S Cheese **0.8.7** included in the App Store, with the official executable and matching sources.
- Separate IZ2S SB4 installation folders and desktop shortcuts.
- Existing SB4 connection, input devices and the other five bundled applications preserved.

Extract the complete archive. On Linux run `sh ./install.sh --launch`; on Windows run `Install.cmd`. GitHub's automatic source archives are for development and omit the Linux Electron runtime kits.

BlitBun 1.15.8, Book Reader 0.1.0, Foldrift 0.3.3, IZ2S Cheese 0.8.7, VacooTube 1.5.7 and IZPSX 0.5.2 are included. BlitBun and VacooTube PC media hosts require Linux. BIOS and game images are not included.

Package integrity, App Store downloads and browser previews are checked on Linux. Native Windows installation and physical console operation have not been tested for this edition.
