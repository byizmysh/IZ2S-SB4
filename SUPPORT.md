# Support

Use the [IZ2S-SB4 Issues](https://github.com/byizmysh/IZ2S-SB4/issues) to describe a problem. Include IZ2S SB4 version, operating system, the selected input device, expected behavior and the visible error. Before sharing logs, remove pairing keys, credentials, personal paths and private network details. Do not attach Nintendo keys, BIOS, games or save files.

For installation, follow [README.md](README.md). For available features, see [COMPATIBILITY.md](COMPATIBILITY.md). Use the packaged Linux or Windows download, not GitHub's automatic source archive.
